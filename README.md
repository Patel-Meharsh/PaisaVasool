# PaisaVasool

## Introduction:

PaisaVasool is an E-Commerce Web Application developed using MERN stack.

The main purpose of this project is to provide an online shopping platform where the users can register, login, search products, browse products, add the products into cart, place orders, make payment through payment gateway and manage their profiles.

The project also contains an admin section where the administrator can manage products, categories, customers, orders and returns.

## Conclusion:

PaisaVasool was developed as a MERN stack E-commerce Project to understand how a complete application works in real-time.

Through this project I learned how the frontend, backend, and database communicate with each other and how features such as authentication, email verification, cart management, orders, payments, admin management and price alerts can be implemented in a real application.
